## 2026-10-06 — точный перенос и окончания строк

Добавлен .gitattributes в рамках первоначальной инициализации: пять файлов
скилла и чатовый адаптер сохраняют точные байты проверенного выпуска.
Остальные текстовые файлы используют LF. Это не меняет поведения скилла.
При git diff --check сохранённые CRLF учитываются через cr-at-eol.
Raw bootstrap-audit.txt содержит локальный путь и исключён из публикации;
публичный publication-verification.json сохраняет сводку без личных путей.
