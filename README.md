# Idea to MVP

AI-скилл для новичка, который хочет выбрать собственный проект или уточнить
сырую идею. Помогает понять пользователя, задачу и следующий шаг проверки.
Идея может быть одна, их может быть несколько; можно начать без идеи.
Решение остаётся за автором, а диалог идёт по одному вопросу.

## Два этапа

**S01 — идея и карточка.** Уточняем, для кого проект, в какой ситуации он
нужен, как задача решается сейчас и что предлагаем. Итог — понятная
[карточка идеи](references/idea-card.md) с причиной выбора, неизвестным
и ближайшей проверкой. «Не знаю» допустимо; случайные числа не требуются.

**S02 — рынок и конкуренты, по запросу.** Продолжаем из карточки: сравниваем
реальные продукты, нынешний способ и косвенные альтернативы одной задачи,
проверяем доступные источники, формулируем гипотезу отличия. Если поиска
или доступа нет, результатом будет честный план исследования. Этап S02
не запускается автоматически после карточки.

Личный, полностью бесплатный для других и коммерческий проект допустимы.
Модель заработка нужна при намерении зарабатывать; бюджет некоммерческого
проекта разбирается по отдельной просьбе. Неизвестные цены и расходы
сохраняются неизвестными. Карточка и сравнение помогают выбрать следующую
проверку; разработку и подробный состав MVP планируют отдельно.

## Установка

Скачайте [готовый ZIP версии 0.1.3](https://github.com/SuperMVP-space/idea-to-MVP/releases/download/v0.1.3/idea-to-mvp.zip)
и распакуйте. Перенесите полученную папку `idea-to-mvp` целиком, чтобы
получился один из путей:

```text
.opencode/skills/idea-to-mvp/SKILL.md
.agents/skills/idea-to-mvp/SKILL.md
```

Первый путь — для OpenCode, второй подходит OpenCode и Codex. Для
Codex выбирайте `.agents/skills/`. При Code → Download ZIP переименуйте
папку `idea-to-MVP-main` в `idea-to-mvp`, затем перенесите её так же.

## Начать работу

В OpenCode используйте обычный запрос:

> Используй idea-to-mvp. Помоги выбрать и упаковать мою идею: [описание].

В Codex явно вызовите скилл:

> $idea-to-mvp Помоги выбрать и упаковать мою идею: [описание].

Для второго этапа передайте результат первого:

> Используй idea-to-mvp. Вот моя карточка: [текст]. Исследуй рынок
> и конкурентов для этой задачи, помоги уточнить фокус.

Проверьте фактическую загрузку скилла и нужной справки в действиях агента.
Полная инструкция — [SKILL.md](SKILL.md).
