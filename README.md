# idea-to-MVP

**«От идеи к проекту»** — скилл `vibecodable-idea` для первых продуктовых
шагов VibeCodable. Текущая версия: **0.1.2**.

Помогает выбрать проект и сделать базовое исследование рынка: сравнить
конкурентов и другие способы решения одной задачи, сформулировать свой фокус.

## Два этапа

1. **S01 — выбрать и упаковать идею.** Если идеи нет, начать со знакомой
   задачи; если несколько — помочь выбрать одну. Результат: карточка,
   однострочник, назначение проекта и следующая проверка.
2. **S02 — исследовать рынок и конкурентов.** По отдельному запросу найти
   и сопоставить прямые/косвенные альтернативы, сохранить ссылки и дату,
   сформулировать гипотезу отличия. Без поиска — план исследования.

Можно делать инструмент для себя, полностью бесплатный проект для других
или проект для заработка. «Пока не решил» допустимо. Базовая модель
заработка нужна, если автор хочет монетизировать проект; бюджет
некоммерческого проекта разбирается по отдельной просьбе.

Выводы о полезности, отличии и оплате — гипотезы для проверки; карточка и
сравнение не доказывают PMF или продажи. Подробный состав MVP и разработка приложения относятся к
следующим этапам курса.

## Быстрый запуск

Скопируйте **всю** папку [skills/vibecodable-idea](skills/vibecodable-idea/)
в проект, с которым работает ваш агент:

```text
OpenCode: .opencode/skills/vibecodable-idea/
Codex:    .agents/skills/vibecodable-idea/
```

В OpenCode напишите:

> Используй vibecodable-idea. Помоги выбрать и упаковать проект:
> [моя идея или интересы]. Начни с S01, после карточки остановись.

В Codex начните тот же запрос с `$vibecodable-idea`.
Проверьте фактическую загрузку скилла и чтение нужных справок.

**Для обычного AI-чата:** вставьте целиком
[docs/chat-instruction.md](docs/chat-instruction.md), затем опишите идею.

## Перейти к исследованию

> Используй vibecodable-idea, этап S02. Вот карточка: [текст или файл].
> Проведи базовое исследование рынка: найди несколько конкурентов,
> сравни аудиторию, сценарий, цены и ограничения для нашей задачи.
> Проверь ссылки, учти нынешний способ решения и помоги выбрать свой фокус.

[Полная памятка запуска](docs/quick-start.md).

## Структура

```text
skills/vibecodable-idea/   Скилл: SKILL.md, agents/ и references/
docs/                     Запуск и полная инструкция для AI-чата
AGENTS.md                 Контракт работы с этим репозиторием
CLAUDE.md                 Импорт AGENTS.md для Claude
Projects/                 Roadmap, план, spec и фичи
Discovery/logs/           Проверки и append-only итоги
Rulebook/                 Индекс локальных правил
```

Инструкции установки опираются на
[OpenCode Skills](https://opencode.ai/docs/skills/) и
[OpenAI Build Skills](https://learn.chatgpt.com/docs/build-skills).
