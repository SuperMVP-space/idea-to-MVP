# Idea to MVP

Idea to MVP помогает превратить исходную мысль в понятный продуктовый замысел
и определить фокус первой версии. Скилл ведёт от выбора идеи к конкретному
пользователю, сравнению альтернатив и решению, какую задачу будет решать MVP.

1. **Выбрать или уточнить идею.** Сопоставляет несколько вариантов или
   развивает одну задумку, помогает выбрать направление и зафиксировать
   причину выбора.

2. **Проработать пользователя, задачу и пользу.** Уточняет конкретного
   человека, ситуацию использования и результат, который должен стать
   для него проще или доступнее.

3. **Упаковать замысел.** Собирает продуктовое описание и карточку идеи:
   пользователь, задача, нынешнее решение, предлагаемое действие,
   предположения и следующая проверка.

4. **Исследовать рынок.** По запросу сравнивает конкурентов и нынешние
   альтернативы по доступным источникам. Показывает сильные стороны
   и ограничения каждого способа, отделяет подтверждённое от гипотез.

5. **Выбрать фокус MVP.** Помогает определить главную задачу и ключевой
   сценарий первой версии. Формулирует гипотезу отличия для выбранного
   пользователя и действие для её проверки.

Результат — оформленная идея, ключевой сценарий первой версии,
сравнение альтернатив и понятный фокус MVP.
