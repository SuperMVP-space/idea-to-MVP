# Spec — опубликованный пакет idea-to-MVP

## Цель и границы

Репозиторий позволяет получить скилл vibecodable-idea 0.1.2 и запустить его
в агенте или обычном AI-чате. S01 — выбрать/упаковать идею, S02 — по запросу
исследовать альтернативы. Личный/полностью бесплатный проект равноправен
коммерческому; «пока не решил» допустимо. Финансовая модель условная.

Владеющий слой — skills/vibecodable-idea/. Docs описывают его использование.
Источник поведения — проверенный выпуск 0.1.2; при переносе его не меняем.
Это документный пакет: код приложения, скрипты и зависимости не добавляются,
TDD неприменим к механическому переносу текста.

## Acceptance criteria и проверки

- AC-01: пять файлов скилла в skills/vibecodable-idea/ побайтно соответствуют
  исходному выпуску; frontmatter валиден. Проверка SHA256 и skill validator.
- AC-02: README и docs/quick-start.md дают правильные пути и запросы для
  S01/S02; docs/chat-instruction.md включает все справки. Проверка локальных
  ссылок, полного встроенного текста и двух независимых вычиток.
- AC-03: нет секретов, личных путей машины автора, персональных данных и
  внутренних материалов курса. Проверка точного состава staged-файлов.
- AC-04: AGENTS — единый источник, CLAUDE импортирует его; roadmap/план/
  фичи/spec/логи/Rulebook связаны. Audit document-профиля и ручная вычитка.
- AC-05: изменения закоммичены и опубликованы без force-push; фактический
  удалённый commit и дерево совпадают с локальными. GitHub API/Git readback.

## Ограничения доказательства

Перенос не является новым пилотом с новичком, GUI-тестом или доказательством
спроса. Прежние сценарные прогоны проверяют поведение исходной 0.1.2, а не
любую модель. Авторские course-артефакты и приватные протоколы не публикуются.
