# Форма спецификации документного изменения

Заполнить до реализации: цель; пользовательский результат; scope и
out-of-scope; владеющий слой; источник истины; критерии приёмки; для каждого
критерия — проверка и ожидаемое evidence; автоматический/ручной smoke;
открытые вопросы. Связать spec с roadmap, планом и конкретной фичей.

Для скрипта/кода нужен полный TDD. Для текста — содержательная проверка
по критериям и источникам, без искусственного RED по словам документа.
